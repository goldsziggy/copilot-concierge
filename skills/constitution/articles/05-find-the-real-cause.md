# Article 5: Find the real cause

Fix where the system first went wrong. A guard over the symptom is not a fix.

## Applies when

Debugging, or a second fix has just failed.

## Do

- Trace each symptom back to its origin with evidence before changing code.
- When two fixes built on the same assumption fail, stop and test the assumption before writing a third.
- Revert what a refuted hypothesis motivated.

## Check

Can you state the cause and show the evidence that rules out the alternatives?
